# СМР-Про: Интеллектуальный поиск строительных расценок

Дипломный проект — микросервисная система интеллектуального поиска по нормативной базе строительных расценок (СМР). Система принимает произвольный текстовый запрос на русском языке и возвращает релевантные расценки, материалы и механизмы, а для агрегированных запросов («малярные работы», «устройство кровли») автоматически формирует технологические комплекты на основе анализа исторических смет.

---

## Как это работает

Каждый запрос проходит четыре последовательных микросервиса:

```
Браузер (UI :8080)
     │
     ▼
Gateway (:5000)  ─── оркестратор пайплайна
     │
     ├─▶ Preprocessing (:5001)  — коррекция опечаток, лемматизация, расширение запроса, классификация
     ├─▶ Retrieval     (:5002)  — гибридный поиск: BM25 + SBERT + PTM, слияние RRF
     ├─▶ Ranking       (:5003)  — переранжирование моделью CatBoost LTR
     └─▶ Postprocessing(:5004)  — технологические комплекты (FP-Growth) и PTM-группы
```

**Пример:** запрос «малярные работы» → исправление → лемматизация → гибридный поиск по BM25+SBERT+PTM-индексу → переранжирование → возврат расценок + автосформированный комплект работ из исторических смет.

## Структура проекта

```
smr-pro-search/
├── common/              # Конфиг, модели БД, логирование, code mapper
├── services/
│   ├── preprocessing/   # Слой 1: SymSpell, pymorphy3, FastText, классификатор
│   ├── retrieval/       # Слой 2: BM25, SBERT/FAISS, PTM-поиск, RRF-слияние
│   ├── ranking/         # Слой 3: извлечение признаков, CatBoost LTR
│   ├── postprocessing/  # Слой 4: FP-Growth комплекты, PTM-группировка
│   └── gateway/         # Оркестратор + feedback API
├── training/            # Пайплайн обучения (8 шагов)
├── ui/                  # Flask веб-интерфейс
├── scripts/             # Инициализация, импорт, утилиты
├── data/                # Данные, модели, индексы (не входят в репозиторий)
│   ├── raw/             # ← сюда кладёте ваши данные
│   ├── smr_pro.db       # генерируется
│   ├── models/          # FastText, SBERT, CatBoost, классификатор
│   └── indices/         # BM25, FAISS, PTM, SymSpell
└── Makefile
```

## Требования

- Python 3.10+
- 4 ГБ RAM (8 ГБ рекомендуется для обучения SBERT)
- GPU опционально — автоматически используется при наличии CUDA

## Быстрый старт

### 1. Установка

```bash
git clone https://github.com/<your-username>/smr-pro-search.git
cd smr-pro-search

python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements-dev.txt
```

### 2. Подготовка данных

Положите свои данные в `data/raw/`:

```
data/raw/
├── smr_catalog.db    ← ваша SMR-Pro база (read-only каталог расценок)
├── estimate_01.xml   ← XML-файлы исторических смет
├── estimate_02.xml
└── 2024/             ← вложенность папок поддерживается
    └── ...
```

> Если у вас нет реальных данных — используйте синтетический демо-набор: `make sample`

### 3. Инициализация и обучение

```bash
# Инициализировать БД
make init

# Импортировать каталог + XML-сметы и обучить все модели (~5–15 мин)
make train

# Или быстрый прогон без SBERT и CatBoost (для разработки):
make train-fast
```

### 4. Запуск

```bash
make run
```

Откройте [http://localhost:8080](http://localhost:8080).

### 5. Остановка

```bash
make stop
```

## Все команды Makefile

| Команда | Описание |
|---|---|
| `make install` | Установить зависимости |
| `make init` | Создать схему SQLite |
| `make import` | Импортировать каталог из `data/raw/smr_catalog.db` |
| `make sample` | Создать синтетические демо-данные (7 позиций) |
| `make train` | Полный пайплайн обучения |
| `make train-fast` | Обучение без SBERT и CatBoost |
| `make train-bm25` | Только BM25-индекс |
| `make train-classifier` | Только классификатор типа запроса |
| `make run` | Запустить все 6 сервисов |
| `make stop` | Остановить все сервисы |
| `make test` | Smoke-тест (health checks + тестовый запрос) |
| `make clean` | Остановить сервисы и удалить БД, модели, индексы |

## Сервисы

| Сервис | Порт | Эндпоинт | Назначение |
|---|---|---|---|
| UI | 8080 | `GET /` | Веб-интерфейс поиска |
| Gateway | 5000 | `POST /search` | Полный пайплайн, feedback API |
| Preprocessing | 5001 | `POST /preprocess` | Нормализация запроса |
| Retrieval | 5002 | `POST /retrieve` | Гибридный поиск |
| Ranking | 5003 | `POST /rank` | Переранжирование |
| Postprocessing | 5004 | `POST /postprocess` | Комплекты и группировка |

Все URL настраиваются через переменные окружения: `PREPROCESS_URL`, `RETRIEVAL_URL`, `RANKING_URL`, `POSTPROCESS_URL`, `GATEWAY_URL`.

## Технологии

| Слой | Инструменты |
|---|---|
| Веб-фреймворк | Python 3.10+, Flask 3 |

## Пайплайн обучения

`make train` запускает 8 шагов последовательно:

1. Импорт каталога из `smr_catalog.db`
2. Парсинг XML-смет (потоковый, рекурсивный)
3. Вычисление статистик и частот
4. Обучение FP-Growth (ассоциативные правила для комплектов)
5. Обучение FastText (расширение запроса синонимами)
6. Дообучение SBERT на парах (ПТМ, расценка)
7. Построение BM25, FAISS, PTM и SymSpell-индексов
8. Обучение классификатора типа запроса

CatBoost-ранкер обучается отдельно командой `make train-catboost` после накопления обратной связи пользователей.
